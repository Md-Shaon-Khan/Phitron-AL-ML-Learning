# Phitron AI/ML Learning

This repository contains all code, notes, assignments, and resources from the **Phitron AI/ML Engineering course**, along with supplementary self-study material on Python, data analysis libraries, and machine learning algorithms.

## Repository Structure

| Folder | Contents |
|---|---|
| `Main Courses/Python and Libraries` | Weekly course modules covering Python fundamentals, OOP, Streamlit, NumPy, Pandas, Matplotlib, and Seaborn |
| `Main Courses/Machine Learning` | Weekly modules on EDA, feature engineering, and ML algorithms (Linear/Logistic Regression, KNN, Decision Tree, Random Forest, SVM) |
| `Optional Course/Introduction to Python & Machine Learning` | Chapter-wise introductory Python and ML exercises |
| `Self Learn` | Independent practice on Python, NumPy, Pandas, Matplotlib, and Scikit-Learn, including notes from *Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow* |
| `Assignment or Exam` | Mid-term assignment, practice modules, and exam solutions |
| `Conceptual Sessions` | Scripts and notebooks from conceptual/theory sessions |
| `Notes` | Consolidated Machine Learning notes (DOCX/PDF) |
| `Dataset` | CSV datasets used across notebooks (Titanic, marks dataset, etc.) |

## Topics Covered

**Python and Libraries**
- Core Python: variables, conditionals, loops, functions, file handling, OOP
- NumPy: array creation, indexing, broadcasting, linear algebra, statistical functions
- Pandas: data cleaning, filtering, grouping, merging, reshaping
- Matplotlib and Seaborn: line, bar, scatter, histogram, pair, and distribution plots
- Streamlit: building interactive data apps

**Machine Learning**
- Exploratory Data Analysis (EDA) and Feature Engineering
- Simple and Multiple Linear Regression (with Gradient Descent)
- Logistic Regression
- K-Nearest Neighbors (KNN) with GridSearchCV
- Decision Tree and Random Forest
- Support Vector Machine (SVM)

## Tech Stack

- **Language:** Python
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn, Scikit-Learn, Streamlit
- **Tools:** Jupyter Notebook

## Datasets Used

Titanic, California Housing, Iris, Wine, Breast Cancer (Wisconsin), Mushroom Classification, Student Performance, Marks Dataset, and other custom CSV files.
